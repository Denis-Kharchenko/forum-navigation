Вход в админку

Здесь организаторы заполняют программу: какая лекция, когда и в каком зале. После сохранения программа попадает на сайт через 1–2 минуты.

Где взять ключ доступа
  1. Владелец репозитория открывает github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → forum-navigation.
  3. Permissions → Repository permissions → Contents: Read and write. Больше ничего не нужно.
  4. Срок действия — до окончания форума. Ключ передаётся организаторам лично, не в общий чат.

Ключ хранится только в браузере этого компьютера и отправляется только на api.github.com.

Помещения

Нажмите на помещение на плане или в списке, чтобы переименовать его. «Заштриховать» убирает помещение из навигации стойки: на плане оно заштриховано и без подписи. Чтобы подписать заштрихованное помещение, впишите ему название. Снимите галочку, чтобы вернуть.

    Сохранить — Ctrl+S. Пока вы работаете, черновик хранится в этом браузере: если вкладка закроется или пропадёт связь, при следующем входе админка предложит его восстановить. Кнопка «Копировать» рядом с записью добавляет такую же лекцию сразу после неё. Записи автоматически сортируются по времени при сохранении. Галочка «Применить ко всем трекам» показывает запись во всех треках — для открытия, обеда, нетворкинга. Если одно и то же место занято двумя лекциями одновременно, админка предупредит.
